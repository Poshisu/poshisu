# Auth redesign notes (RDX-04)

_Date: 2026-05-24_

## Before vs after

## Before
- Welcome/auth entry surfaces looked plain and generic.
- Card hierarchy and copy felt utility-first rather than premium coach-first.
- CTA hierarchy was functional but not aligned with the redesign brief tone.

## After
- Welcome screen now uses softer ambient gradient/orb treatment and updated copy hierarchy.
- Auth layout wraps login/signup in a premium shell with calm background treatment.
- Login/subtitle copy updated to: "Pick up where your coach left off."
- Signup subtitle updated to: "Set up your coach in under two minutes."
- Divider labels now clarify email auth mode ("Or sign in with email" / "Or sign up with email").

## Behavior guardrail
- Auth provider logic, form validation, and server actions were not changed in this redesign pass.
